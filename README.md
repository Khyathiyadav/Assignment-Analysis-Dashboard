# Procrastination Analysis Dashboard (Power BI)

## Project Overview
This project analyzes **student procrastination behavior** using a structured dataset and an interactive **Power BI dashboard**.  
The goal is to understand how procrastination hours relate to **stress levels**, **academic majors**, **activities**, and **assignment deadlines**.

The dashboard provides actionable insights into patterns of procrastination and academic stress across different student groups.

---

## Objectives
- Analyze the relationship between **procrastination hours and stress levels**
- Identify **majors with higher procrastination and stress**
- Understand common **procrastination activities**
- Study **assignment due trends** across majors
- Highlight students with **high stress and procrastination levels**

---

## Dataset Description
The dataset consists of student-level academic and behavioral data, including:

- Student Name  
- Major  
- Procrastination Hours per Day  
- Stress Level  
- Procrastination Activity  
- Assignment Due (in Days)  

 **Processed dataset used:**  
`procrastination_dataset_processed.xlsx`

---

## Tools & Technologies
- **Power BI** – Data visualization and dashboard creation  
- **Power Query** – Data cleaning and transformation  
- **Excel** – Dataset preprocessing  

---

## Data Preparation & Cleaning
The following steps were performed before building the dashboard:
- Removed missing and inconsistent values
- Standardized major names
- Converted procrastination hours and stress levels into numeric format
- Ensured clean relationships between attributes for accurate aggregation
- Created calculated measures for averages and totals

---

## Dashboard Components
The Power BI dashboard includes:

### Key KPIs
- **High Stressed People:** 82  
- **Average Procrastination Hours per Day:** 6.40 hours  

### Visualizations
- Stress level vs procrastination hours per day  
- Procrastination hours by **major**
- Stress levels by **major**
- Student count distribution by major
- Procrastination hours by **activity**
- Assignment due (in days) by major
- Interactive filters for major selection

---

## Key Insights
- Higher procrastination hours generally correlate with **higher stress levels**
- Certain majors show **consistently higher procrastination patterns**
- Activities like **binge-watching, gaming, and social media scrolling** contribute heavily to procrastination
- Most students delay assignments until deadlines are closer
- Academic stress varies noticeably across different majors
